# 📚 Flashcard Quiz App

A simple and interactive Android Flashcard Quiz application built using **Kotlin** and **Jetpack Compose**.

## ✨ Features

- 📖 View flashcards with questions and answers
- 👀 Show and hide answers
- ⬅️ Previous and ➡️ Next navigation
- ➕ Add new flashcards
- ✏️ Edit existing flashcards
- 🗑️ Delete flashcards with confirmation
- 💾 Flashcards are saved permanently on the device
- 🎨 Clean and user-friendly interface

## 🛠️ Technologies Used

- Kotlin
- Android Studio
- Jetpack Compose
- Material 3
- SharedPreferences
- JSON

## 📱 Application

The Flashcard Quiz App helps users study and revise topics using digital flashcards.

Users can create their own flashcards, view questions, reveal answers, edit cards, and delete cards when they are no longer needed.

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project in Android Studio.
3. Allow Gradle to sync.
4. Connect an Android device or start an Android Emulator.
5. Click the **Run ▶️** button.
6. The Flashcard Quiz App will launch on the device.
